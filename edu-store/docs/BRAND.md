# 멜리사 에듀 브랜드 & 컨셉 정의

> **확정 브랜드명: 멜리사 에듀** (아래 후보는 초안 단계의 기록입니다.)

## 1. 브랜드명 후보

| 후보 | 의미 | 느낌 |
| --- | --- | --- |
| **바른풀이** | 정확한 풀이, 바른 공부 습관 | 정확성 강조, 학부모 신뢰도 높음 |
| **오늘한장** | 오늘 한 장(세트)부터 시작 | 부담 없는 실천, 자기주도 강조 |
| **정석노트** | 기본에 충실한 정리 노트 | 차분하고 전문적 |
| **스텝지(Stepji)** | 단계(step) + 지(紙, 종이) | PDF 자료라는 형태와 단계별 학습을 함께 표현 |

> 사이트에서는 `NEXT_PUBLIC_BRAND_NAME` 환경 변수 하나만 바꾸면 전체에 반영됩니다. 확정 전 특허청 KIPRIS(상표 41류·16류)와 도메인 사용 가능 여부를 확인하세요.

## 2. 슬로건 후보

1. **필요한 만큼, 정확하게.** (메인 슬로건, 사이트 히어로에 적용)
2. **오늘 풀 한 세트부터.** 내 공부를 내가 설계하는 자료
3. **검수한 자료, 바로 다운로드.** 기다림 없이 오늘 계획에 넣으세요

## 3. 핵심 메시지와 차별점

**핵심 메시지:** 많이 담은 자료보다, 정확하고 지금 바로 쓸 수 있는 자료.

| 축 | 약속 | 사이트에서 보여주는 근거 |
| --- | --- | --- |
| 정확성 | 모든 문항 출처 표기, 정답·해설 2인 검수, 오류 시 수정본 재배포 | 상세 페이지 설명, FAQ "오류가 있으면?" |
| 효율성 | 단원·유형별로 묶어 필요한 부분만 고르기, '왜 그 답인지'에 집중한 해설 | 목차 공개, 필터(과목·학년·유형) |
| 자기주도성 | 체크리스트·회독표·오답 분류 시트 동봉, 플래너 상품 | 자기주도학습 카테고리, 히어로의 주간 계획 비주얼 |
| 즉시 다운로드 | 결제 승인 즉시 내 자료함에서 다운로드 | 결제 완료 화면 → 내 자료함 바로가기 |

**톤 원칙:** "1등급 보장", "100% 적중"처럼 결과를 약속하지 않습니다. 구성·검수 방식·환불 기준처럼 확인 가능한 사실로 신뢰를 만듭니다.
