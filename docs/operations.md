# Afterline 운영 안내

신청부터 상담까지 쓰는 문자 템플릿과 체크리스트입니다. `[ ]`는 상황에 맞게 채웁니다.

---

## 1. 흐름

| 단계 | 할 일 | 문자 |
|---|---|---|
| 신청 접수 | 신청 내용 확인, 상담 상품 판단 | ① 입금 안내 |
| 입금 확인 | 입금자명과 금액 대조 | ② 일정 확정 |
| 상담 전날 | 일정 다시 안내 | ③ 전날 안내 |
| 상담 당일 | 약속 시간에 상담 전용 번호로 발신 | (연결 안 될 때) ④ 부재 안내 |
| 상담 후 | 정한 행동 요약 전달 | ⑤ 상담 후 정리 |

- 입금 기한이 지나도록 입금이 없으면 ⑥ 신청 취소 문자를 보냅니다.
- 모든 문자와 전화는 **상담 전용 번호**로만 보냅니다. 개인 번호나 발신번호 표시제한(`*23`)은 쓰지 않습니다.

---

## 2. 문자 템플릿

### ① 입금 안내

```
[Afterline] 상담 신청이 접수되었습니다.

· 상담: [상품명]
· 금액: [금액]원
· 입금 계좌: [은행] [계좌번호] ([예금주])
· 입금자명: 이름+전화번호 뒤 4자리 (예: 홍길동1234)
· 입금 기한: [M월 D일 H시]까지

입금이 확인되면 통화 일정을 안내드립니다.
현금영수증이 필요하시면 이 번호로 알려 주세요.
```

### ② 일정 확정

```
[Afterline] 입금이 확인되었습니다.

· 상담 일시: [M월 D일 (요일) H시 M분]
· 상담 시간: [ ]분
· 전화드릴 번호: [상담 전용 번호]

번호를 저장해 두시면 전화를 놓치지 않습니다.
상담 전 필요한 대화 캡처가 있다면 상대의 이름과 사진은 가린 뒤 준비해 주세요.
일정 변경은 상담 [ ]시간 전까지 가능합니다.
```

### ③ 전날 안내

```
[Afterline] 내일 [H시 M분]에 [상담 전용 번호]로 전화드립니다.
통화가 편한 장소에서 받아 주세요.
```

### ④ 부재 안내

```
[Afterline] 약속한 시간에 전화드렸으나 연결되지 않았습니다.
[ ]분 뒤에 한 번 더 전화드리겠습니다.
```

### ⑤ 상담 후 정리

```
[Afterline] 오늘 상담에서 정한 내용입니다.

· 지금의 방향: [연락 / 대기 / 정리]
· 다음 행동: [한 문장]
· 하지 않을 것: [한 문장]
· 다시 볼 시점: [M월 D일 무렵]

상황이 바뀌면 이 번호로 알려 주세요.
```

### ⑥ 신청 취소

```
[Afterline] 입금 기한이 지나 상담 신청이 취소되었습니다.
다시 신청하시려면 홈페이지에서 접수해 주세요.
```

---

## 3. 문자 쓸 때 지킬 것

- 상담 내용(이별 사정, 상대 이야기)은 문자에 쓰지 않습니다. 휴대폰을 다른 사람이 볼 수 있습니다.
- 위로나 결과 예측 문장을 넣지 않습니다. "잘될 거예요", "연락 올 거예요" 같은 말입니다.
- 계좌번호는 홈페이지에 올리지 않고 ① 문자로만 보냅니다.

---

## 4. 시작 전 체크리스트

- [ ] 상담 전용 번호 개통 (통신사 투넘버 또는 070)
- [ ] 사업자등록, 사업자 명의 계좌
- [ ] 통신판매업 신고 필요 여부 확인
- [ ] 현금영수증 의무 발행 업종인지 세무사 확인
- [ ] 상품별 가격, 상담 1회 시간 확정
- [ ] 환불 기준 시간 확정 → `site/build.py`의 TERMS, 홈 FAQ에 반영
- [ ] 자료 보관 기간 확정 → `site/build.py`의 PRIVACY에 반영
- [ ] 개인정보처리방침과 이용약관 전문가 검토
- [ ] 신청서 접수 연결 (현재는 전송되지 않음)
- [ ] 도메인 확정 → `site/build.py`의 `DOMAIN` 변경 후 `python3 build.py`
