# AFTERLINE 디자인 기준 (v2)

- 분위기: 밝고 차분하고 부드러운 프리미엄. 화이트, 아이보리, 베이지, 소프트 그레이, 밝은 우드 톤. 어두운 럭셔리 무드는 피합니다.
- 컬러: Ivory `#F6F3EE` 배경 · Text `#222222` · Secondary `#65615B` · Deep Navy `#17202B`(버튼만) · Soft Beige `#E9E3DA`(A Quiet Decision, 푸터) · Accent `#8A7563`(번호, 라벨. 5% 이하)
- 글꼴: 영문 브랜드·라벨·숫자 Cormorant Garamond · 한글 제목 Hahmlet(가는 굵기) · 본문 Pretendard. 세 글꼴 모두 `site/fonts/`에 직접 포함(SIL OFL). Pretendard는 KS X 1001 한글 2,350자와 사이트에 쓰인 글자로 줄인 파일입니다.
- 워드마크: AFTERLINE, letter-spacing 0.32em
- 카드 없음. 얇은 선과 여백으로 구분. 아이콘 대신 번호와 화살표만.
- 사진: 밝은 자연광 인물 사진 4~6장을 페이지 전체에 나눠 배치. 하트, 장미, 핑크·보라 그라데이션 금지.
- 움직임: 느린 fade-in, 이미지 미세 확대, 밑줄 hover만.

## 사진
사람이 등장하는 밝은 자연광 사진을 씁니다. 표정은 사색적이고 조용한 정도까지만. 어두운 호텔 라운지 톤, 우는 표정, 드라마틱한 포즈는 쓰지 않습니다.

| 파일 | 위치 | 장면 |
|---|---|---|
| `hero.webp` (4:5) | 히어로 | 밝은 복도 벽에 기대어 스마트폰을 쥔 여성 |
| `consultation.webp` (4:5) | Consultation 제목 옆 | 밝은 식탁에서 스마트폰을 보는 남성 |
| `cases.webp` (16:9) | Cases 제목 아래 | 밝은 카페에서 떨어져 앉은 두 사람 |
| `closing.webp` (4:5) | 마지막 CTA | 노을빛 강변 테라스의 여성 |

받으면 넣을 자리(아직 파일 없음): 창가 카페에서 스마트폰을 보는 여성 → 히어로(지금 히어로 사진은 '이런 상황이라면'으로 이동), 햇살 드는 거실 소파의 여성 → Brand Statement.
